# NEXORA — Modern Blog Website

> **Ideas for a smarter digital future.**

NEXORA is a modern, responsive editorial-style blog website created as part of the **CODSOFT Front-End Web Development Internship — Task 5: Blog Website**.

The project focuses on creating a professional reading experience with organized articles, responsive layouts, search and filtering, article detail views, comments, social sharing, related articles, and dark/light theme support.

## 🌐 Visit Website

**Live Demo:**  
Visit NEXORA Blog Website: https://sowji1176.github.io/CodSoft-Blog-Website-Task/

## 📌 Project Overview

NEXORA is a fictional digital publication covering topics related to:

- Artificial Intelligence
- Technology
- UI/UX Design
- Career Development
- Productivity
- Digital Skills
- Innovation

The website was designed to provide a clean and engaging reading experience while demonstrating modern front-end development techniques.

## ✨ Features

### 🏠 Homepage

- Professional editorial-style hero section
- Featured article section
- Latest articles grid
- Article cards with:
  - Cover image
  - Category
  - Title
  - Excerpt
  - Publication date
  - Reading time
  - Tags
  - Read Article button

### 🔎 Search

- Search articles by:
  - Title
  - Category
  - Tags
  - Article content
  - Excerpt
- Real-time search filtering
- Clear search option
- No-results state

### 🗂️ Categories

Articles can be filtered by:

- All
- AI & Innovation
- Technology
- Design
- Career
- Productivity

### 🏷️ Tags

Users can select article tags to discover related content.

### 📖 Article Detail Pages

Articles open dynamically without requiring separate HTML files.

Each article includes:

- Category
- Article title
- Author
- Publication date
- Reading time
- Featured image
- Long-form article content
- Headings and subheadings
- Lists
- Blockquotes
- Tags
- Related articles

### 🔗 Related Articles

The article detail page automatically displays related articles based on:

- Matching category
- Matching tags

The complete related article card is clickable, allowing users to open the article by clicking the image, title, metadata, card area, or Read Article button.

### 📈 Reading Progress

A reading progress indicator shows the user's progress while reading an article.

### 💬 Comments

The website includes a client-side comment system using Local Storage.

Users can:

- Enter their name
- Write a comment
- Submit comments
- View previously submitted comments

Comments are stored locally in the browser.

### 📤 Social Sharing

Articles can be shared through:

- LinkedIn
- Facebook
- X
- Copy Link

### 🌙 Dark / Light Mode

Users can switch between:

- Dark Mode
- Light Mode

The selected theme is saved using Local Storage.

### 📱 Responsive Design

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

### 📱 Mobile Navigation

Includes:

- Hamburger menu
- Mobile navigation panel
- Overlay
- Responsive navigation behavior

### 📩 Contact Form

Includes:

- Name validation
- Email validation
- Message validation
- Error messages
- Submission success state

### ⬆️ Back to Top

A floating Back to Top button appears after scrolling and smoothly returns the user to the beginning of the page.

### 🎨 Scroll Reveal Animations

Content sections are progressively revealed as the user scrolls through the website.
